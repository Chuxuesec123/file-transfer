# 文件互传

浏览器里在本机与虚拟机之间拖拽传文件，纯前端页面 + 可选的标准库服务端。

## 启动

```bash
cd file-transfer
python3 server.py 80          # 完整功能：浏览 / 下载 / 上传 / 删除 / 新建文件夹
```

也可以直接用原生命令（只读：只能浏览和下载）：

```bash
python3 -m http.server 80
```

两者都在本目录下启动，浏览器打开 `http://<本机IP>/`。

## 文件放在哪

共享目录固定为页面同级的 `files/`（服务端启动时会自动创建）：

```
file-transfer/
├── index.html  app.js  styles.css  server.py
└── files/          ← 上传与下载的文件都在这里
```

这样做是因为原生 `http.server` 会把 `index.html` 当作目录首页返回，直接放在根目录就读不到文件列表了。

## 页面功能

- 拖拽上传、多文件批量上传、上传文件夹（保留目录结构），带进度 / 取消 / 重试
- 目录浏览、面包屑跳转、按名称 / 大小 / 时间排序、即时筛选
- 一键下载、新窗口预览图片 / 视频 / PDF / 文本
- 删除文件、删除空目录、新建文件夹
- 深色 / 浅色主题自动记忆，`/` 聚焦筛选，`Esc` 清空，`Backspace` 返回上级

## 说明

- 原生 `python3 -m http.server` 不支持写操作，页面会自动显示「仅下载」并隐藏上传入口，仍可浏览、排序、下载。
- `server.py` 只用 Python 标准库，端口参数与 http.server 一致，默认 8000；监听 80 端口需要 root。
- 上传 / 删除 / 新建文件夹只允许作用在 `files/` 内，页面自身的 html、js、css 不会被误删；目录只能删除空的。
- 上传先写入 `*.part` 再原子替换，传输中断（断网、取消、关页面）不会留下半截文件或覆盖原文件。
